Navigation

CTRL+P - quickly opens a search bar that I can use to type. I had to use this to jump into files in my project onboarding without having to use the sidebar.
CTRL+G - this lets me jump to a line when I type in the exact line number. This is handy when debugging error messages that give me the exact line number.

Editing

CTRL+C - This lets me copy text that I have selected.
CTRL+V - This lets me paste the selected text that I copied.
CTRL+SHIFT+LEFT ARROW KEY - This lets me select words one by one to the left when I want to copy part of a line and not the entire line.
CTRL+SHIFT+RIGHT ARROW KEY - This lets me select words one by one to the right when I want to copy part of a line and not the entire line.
CTRL+ALT+DOWN/UP - Adds extra cursors above or below. This lets me easily add a tab space to muliple lines if I want to, so it saves a lo of time by getting rid of repetitive typing.
SHIFT+ALT+F - This allows me to format documents, so that I make sure my work is consistent.
ALT+UP/DOWN - This allows me to move an entire line up or down without having to select text and copy and paste.
CTRL+D - This allows me to select duplicates of the text I have selected. So I can easily rename a variable using this way.

Debugging

F5 - This launches the debugger.

Terminal Commands

Ctrl+` (backtick) — Toggle Integrated Terminal. It opens or closes the VS Code terminal. It saves me time since I often use the terminal to run docker commands, npm scripts and git operations.

Which shortcuts do you think will be the most useful in your daily work?

The shortcuts in the editing section will be the most useful to me since there is a lot of editing involved when debugging and writing code.

How can keyboard shortcuts improve your productivity?

It will decrease the time taken to complete mundane tasks and will increase productivity by doing activities much faster and efficiently.
